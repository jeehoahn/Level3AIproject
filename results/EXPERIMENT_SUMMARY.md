# 허프만 코딩 비교: 1회 실행 예시

실행 환경: Python 3.13.5 / Linux, 6.18.57
실험 조건: 코드 생성·파일 읽기·파일 쓰기 포함, 파일별·알고리즘별 **1회 측정**, 동일 실행 환경.
CSV의 압축 파일/복원 파일 경로는 샘플 배포에서 제외했습니다. GUI에서 실험하면 실제 경로가 저장됩니다.
시간은 예시 실행 환경 기준이며 Windows 및 다른 PC에서는 달라집니다.

## 해석 시 주의

- 균일 ASCII의 실측 절감률이 0이 아닌 이유는 94종의 인쇄 가능한 ASCII를 균등 확률로 샘플링했기 때문입니다(256종 바이트의 균일 분포가 아닙니다).
- 한글 텍스트는 UTF-8 멀티바이트이므로 같은 500,000자라도 원본 바이트 크기가 다릅니다.
- 정적 허프만의 헤더는 256바이트 코드 길이표를 포함하고 FGK는 동기화 규칙만 사용하므로 헤더가 작습니다.
- FGK는 입력 도중 트리를 자주 갱신하여 일반적으로 단순 Python 구현에서 정적 방식보다 처리 시간이 길어집니다.
- 성능 차이의 신뢰도를 높이려면 각 실험을 최소 3~5회 반복하고 평균 및 표준편차를 따로 구하세요.
- **모든 결과에서 복원 바이트 손실률 0%**를 확인했습니다. (12 파일 × 2 알고리즘)
